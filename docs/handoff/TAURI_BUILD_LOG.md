## How to build the .app

```bash
cd ~/ev-auto-trader-canada
npm install
npm run icon                                          # only when icon source PNG changes
npm run static-meta                                   # bake snapshots + mtimes into data/meta-static.json
npx tauri build --target aarch64-apple-darwin
# .app at: src-tauri/target/aarch64-apple-darwin/release/bundle/macos/EV.trader CA.app
```

First build = 5-10 min (compiles ~400 Rust crates). Incremental rebuilds = 30-90 sec.

## How to verify it works

```bash
open "src-tauri/target/aarch64-apple-darwin/release/bundle/macos/EV.trader CA.app"
```

The window opens to `/`. Test sequence:
1. Click around all routes — homepage, inventory, compare, pick-a-model, dossier, dealer pages.
2. Verify the nav shows `⟳ Refresh` (only in the Tauri build, hidden on Vercel).
3. Click any unit row → dossier → click `⟳ Verify availability`. Should ping AutoTrader and report active/removed/challenged.
4. Click `⟳ Refresh` in nav → modal opens. (Don't click Start unless you want to actually run the refresh script.)
